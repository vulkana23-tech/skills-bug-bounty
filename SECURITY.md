## 📋 Security Policy & Compliance Standards

The **bug-bounty-skills** collection adheres to strict ethical framing, defensive-first compliance, and responsible disclosure standards.

---

## 🔒 Reporting a Vulnerability

If you discover a security issue within this repository or associated tooling, please report it responsibly:

1. **Email Channel**: Send details to `security@vulkana23.tech` or open a private **GitHub Security Advisory**.
2. **Details to Include**:
   - Description of the issue or misconfiguration
   - Steps to reproduce in a safe, isolated environment
   - Proposed remediation patch or mitigation guide
3. **Response SLA**:
   - Initial Acknowledgment: within **24 hours**.
   - Vulnerability Triage & Patch: within **72 hours**.
