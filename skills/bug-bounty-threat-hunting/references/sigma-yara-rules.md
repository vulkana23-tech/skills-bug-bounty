# Threat Hunting & Detection Reference

## 1. Metodología de Caza de Amenazas

1. **Definición de Hipótesis**: Basarse en marcos como MITRE ATT&CK para definir patrones de ataque a buscar.
2. **Validación y Pruebas**: Probar las reglas de detección contra datos históricos para reducir falsos positivos.

## 2. Recomendaciones de Detección

- Mantenga actualizadas las colecciones de reglas de detección comunitarias en su plataforma SIEM/EDR.
- Automatice la respuesta a incidentes para aislar hosts infectados cuando se active una regla de alta severidad.
