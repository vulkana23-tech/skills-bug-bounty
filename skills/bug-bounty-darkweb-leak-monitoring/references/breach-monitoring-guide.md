# Data Breach & Dark Web Monitoring Reference

## 1. Riesgos de Credenciales Filtradas

La reutilización de contraseñas expuestas en filtraciones secundarias permite a atacantes realizar ataques de relleno de credenciales (Credential Stuffing) exitosos sobre sistemas corporativos.

## 2. Remediación Segura

- Implemente autenticación multifactor (MFA) obligatoria en todos los puntos de entrada externos (VPN, SSO, Correo).
- Fuerce el restablecimiento inmediato de contraseñas comprometidas detectadas en monitoreos de brechas.
