# Attack Surface Mapping Reference Guide

## 1. Integración de Fuentes en Configuración

- Configure claves de API en el archivo `config.ini` de Amass (AlienVault, BinaryEdge, Censys, Chaos, PassiveTotal, SecurityTrails, Shodan) para maximizar la cobertura.

## 2. Remediación Segura

- Realice auditorías periódicas de superficie de ataque para identificar activos "sombra" (Shadow IT) o servidores olvidados sin parches de seguridad.
