# Entity & Metadata Extraction Reference Guide

## 1. Comandos de Extracción Metadatos

```bash
# Extracción de metadatos de autor con exiftool
exiftool -Creator -Author -Producer -software document.pdf
```

## 2. Remediación Segura

- Sanitice y elimine los metadatos de archivos antes de su publicación en sitios web corporativos.
