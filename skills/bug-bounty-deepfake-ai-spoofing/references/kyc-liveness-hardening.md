# Biometric Liveness Hardening Reference

## 1. Remediación Segura

- Utilice mecanismos de prueba de vida activos aleatorios (ej. solicitar movimientos de cabeza o lecturas de códigos en pantalla en tiempo real).
- Firme digitalmente las capturas de cámara a nivel de hardware/enclave seguro antes de transmitirlas a la API del servidor.
