# Open Asset Model (OAM) Reference Guide

## 1. Ejemplo de Objeto OAM (FQDN)

```json
{
  "type": "FQDN",
  "asset": {
    "name": "subdomain.target.com"
  }
}
```

## 2. Beneficios de OAM en Auditorías

- Permite compartir datos de inventario entre distintas herramientas de escaneo sin requerir adaptadores de formato complejos.
