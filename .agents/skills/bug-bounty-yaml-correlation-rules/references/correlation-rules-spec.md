# Correlation Rules Specification Reference

## 1. Operadores Lógicos de Correlación

- **AND**: Se activan cuando ambos eventos ocurren sobre la misma entidad objetivo.
- **THRESHOLD**: Se activan cuando el recuento de un evento supera un límite en una ventana de tiempo definida.

## 2. Remediación Segura

- Utilice motores de correlación para reducir la fatiga de alertas agrupando eventos aislados de baja severidad en hallazgos compuestos de alto impacto.
