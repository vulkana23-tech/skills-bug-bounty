# SpiderFoot CLI & Automation Reference

## 1. Filtrado de Módulos por Objetivo

- Use `-m` para especificar únicamente módulos pasivos cuando requiera auditorías sin interacción directa (ej. `sfp_virustotal,sfp_shodan`).

## 2. Remediación Segura

- Centralice la gestión de claves de API de módulos en archivos de entorno seguros para evitar la exposición accidental de cuotas.
