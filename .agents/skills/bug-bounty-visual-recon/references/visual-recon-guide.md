# Visual Reconnaissance Reference Guide

## 1. Cadena de Comandos para Gowitness

```bash
gowitness file -f live_urls.txt --threads 10
```

## 2. Ventajas del Reconocimiento Visual

- Reduce drásticamente el tiempo de análisis en objetivos con miles de subdominios.
- Permite identificar visualmente aplicaciones heredadas (legacy UI) con mayor probabilidad de contener vulnerabilidades históricas.
