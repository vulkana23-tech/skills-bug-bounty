# Parameter Mining & Endpoint Discovery Reference

## 1. Comandos de Prueba Eficientes

```bash
# Infección de parámetros con Arjun
arjun -u https://target.com/api/user -m GET
```

## 2. Remediación Segura

- Elimine código de depuración y parámetros de prueba no utilizados antes de desplegar aplicaciones a entornos de producción.
- Minimice la exposición de endpoints administrativos o de prueba en bundle files de JavaScript del cliente.
