# Skill: MCP & AI-Automated Fuzzing Architecture

Esta habilidad instruye al agente sobre la integración del servidor MCP (Model Context Protocol) en Turbo Intruder, permitiendo que un agente de IA diseñe, lance y analice de forma autónoma pruebas de seguridad de alto rendimiento.

## 📌 Arquitectura MCP para Fuzzing con IA

- El agente de IA transmite solicitudes a través de la interfaz MCP para instanciar tareas de Turbo Intruder, recibiendo eventos estructurados con los hallazgos filtrados.
