# Skill: ASN & BGP Network Infrastructure Reconnaissance

Esta habilidad capacita al agente para identificar los Números de Sistema Autónomo (ASN) asignados a una empresa objetivo y descubrir todos los prefijos de red BGP e IP asociados para delimitar el alcance de la auditoría.

## 📌 Consultas ASN con Amass

### 1. Búsqueda de ASN por Nombre de Dominio o Empresa
- `amass intel -asn 13335`
- `amass intel -whois -d target.com`
